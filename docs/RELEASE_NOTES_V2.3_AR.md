# سجل تحديث AL AKRAM V2.3

## مساعد المحامي المتكامل
- إضافة واجهة أسئلة وأجوبة من داخل تفاصيل كل قضية.
- دعم أسئلة حول بيانات القضية والمستندات ونصوص OCR والجلسات والمهام والمراجع القانونية.
- إضافة أسئلة سريعة، منها المواد القانونية والمستندات والجلسة القادمة والبحث عن مبالغ وتواريخ انتهاء العقود.
- إظهار المصادر المرتبطة بالإجابة، والتحقق خادمياً من أن معرف المصدر موجود فعلاً ضمن بيانات القضية.
- استخدام Supabase Edge Function لحماية مفتاح Gemini؛ المفتاح غير موجود في ملفات التطبيق.

## إعدادات التشغيل
- نشر `legal-assistant` و`analyze-case` عبر Supabase CLI.
- إضافة `GEMINI_API_KEY` في Supabase Secrets عند الاستعداد للتشغيل.
- راجع `LEGAL_ASSISTANT_V2.3_SETUP_AR.md` للتعليمات والحدود.

## ملاحظات الاختبار
لم يتوفر Flutter SDK أو Deno في بيئة إعداد الحزمة، لذلك لم يتم تنفيذ `flutter analyze` أو بناء APK أو فحص نشر Edge Functions. يلزم إجراء هذه الخطوات على جهاز التطوير قبل إصدار APK للاستخدام الفعلي.
