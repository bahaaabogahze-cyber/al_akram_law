# الأكرم للمحاماة – V2.2 Smart Case Management

## ما أضيف في هذا التحديث
- بطاقة تحليل ذكي داخل تفاصيل القضية.
- إرسال بيانات القضية والمستندات التي تحتوي نص OCR والجلسات والمهام المرتبطة إلى وظيفة آمنة على Supabase لتحليلها.
- تقسيم نتيجة التحليل إلى أطراف ووقائع وتواريخ والتزامات ومستندات ومسائل قانونية ومراجع ومعلومات ناقصة وخطوات مقترحة وتنبيهات مراجعة.
- حفظ سجل التحليل في جدول `case_analyses` بسياسات RLS بحيث لا يرى المستخدم إلا تحليلاته.
- تحميل آخر تحليل محفوظ عند فتح ملف القضية.
- مفتاح Gemini غير موجود في التطبيق أو ملفات المصدر؛ يضاف لاحقاً إلى Supabase Secrets.

## متطلبات التفعيل
1. تنفيذ `supabase/migrations/0012_smart_case_analysis.sql` مرة واحدة.
2. نشر وظيفة `analyze-case`.
3. إضافة `GEMINI_API_KEY` إلى Supabase Edge Function Secrets عند الرغبة في تفعيل التحليل.
4. راجع `docs/SMART_CASE_V2.2_SETUP_AR.md` للتفاصيل.

## ما لم يتم ادعاء اكتماله
- هذه النسخة لا تضيف إشعارات نظام مجدولة تعمل بعد إغلاق التطبيق؛ الموجود حالياً هو نظام الإشعارات الداخلي السابق.
- جودة التحليل مرتبطة بنصوص OCR والمراجع القانونية المتاحة فعلياً في قاعدة البيانات.
- لا يمكن اعتماد التحليل بديلاً عن مراجعة المحامي أو النص الرسمي النافذ.
