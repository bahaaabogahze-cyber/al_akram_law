# مساعد المحامي المتكامل – إعداد V2.3

## ما الذي يفعله؟
- يفتح من داخل تفاصيل القضية ويستقبل أسئلة عن القضية المحددة.
- يجمع بيانات القضية ومستنداتها ونص OCR المتاح والجلسات والمهام والمراجع القانونية المطابقة.
- يعرض مصادر الإجابة من سجل مصادر معروف في الخادم؛ وتُرفض معرفات المصادر التي لا تطابق سجلات القضية الفعلية.
- لا يقرأ ملفات التخزين الثنائية مباشرة؛ يعتمد على النص المستخرج المخزن في `documents.ocr_text`. إذا لم يُستخرج نص المستند فلن يستطيع البحث داخل محتواه.
- العقود تُعامل كمستندات قضية إذا كانت محفوظة في جدول `documents` وكان نصها المستخرج متاحاً. لا يوجد ربط مستقل بجدول عقود في هذه النسخة.

## النشر
من مجلد المشروع وبعد ربط Supabase CLI بالمشروع الصحيح:

```bash
supabase functions deploy legal-assistant
```

وظيفة `analyze-case` الحالية تستخدم المفتاح نفسه، لذا انشرها أيضاً إذا لم تكن منشورة:

```bash
supabase functions deploy analyze-case
```

## إضافة المفتاح لاحقاً
لا تضع المفتاح في Flutter أو ملفات المشروع أو GitHub. أضفه إلى Supabase Secrets من لوحة تحكم Supabase أو عبر CLI:

```bash
supabase secrets set GEMINI_API_KEY=YOUR_GEMINI_KEY
```

اختياري لتغيير النموذج:

```bash
supabase secrets set GEMINI_MODEL=gemini-2.5-flash
```

استبدل `YOUR_GEMINI_KEY` بالمفتاح من جهازك؛ لا ترسله في المحادثة. لا يوجد مفتاح مضمّن في هذه الحزمة.

## طريقة الاستخدام
1. سجل الدخول إلى التطبيق.
2. افتح القضايا ثم اختر القضية المطلوبة.
3. افتح بطاقة «مساعد المحامي المتكامل».
4. اختر سؤالاً جاهزاً أو اكتب سؤالك.
5. راجع قائمة «مصادر الإجابة» وافتح المستند الأصلي أو سجل الجلسة للتحقق.

## حدود مهمة
- المساعد مقيد ببيانات القضية التي فتحها المستخدم وبصلاحيات Supabase RLS.
- البحث في نص المستندات يعتمد على OCR. المستند المصور الذي لا يحتوي `ocr_text` لن يكون قابلاً للبحث النصي حتى تتم معالجته.
- لا تعتبر الإجابة رأياً قانونياً نهائياً، وتحقق من النصوص القانونية النافذة والمصدر الرسمي.
- لا يدّعي المساعد وجود معلومة عند غيابها عن البيانات المتاحة.
