# إعداد ميزات القضية الذكية – V2.2

## 1) قاعدة البيانات
بعد التأكد من وجود نسخة احتياطية، نفّذ ملف الترحيل الجديد فقط:
`supabase/migrations/0012_smart_case_analysis.sql`

لا تعِد تشغيل ملفات الترحيل السابقة إذا سبق تنفيذها.

## 2) نشر وظيفة تحليل القضية
من جذر المشروع:

```bash
supabase functions deploy analyze-case
```

## 3) إضافة مفتاح Gemini لاحقاً
اترك خانة المفتاح فارغة في التطبيق؛ المفتاح لا يوضع في Flutter أو APK.
أضفه في Supabase Dashboard → Project Settings → Edge Functions → Secrets، بالاسم:

`GEMINI_API_KEY`

ويمكن تحديد النموذج اختيارياً باسم `GEMINI_MODEL`، والقيمة الافتراضية `gemini-2.5-flash`.

لا ترسل المفتاح في المحادثة ولا تضعه في GitHub.

## 4) حدود التحليل
التحليل أداة مساعدة للمحامي وليس رأياً قانونياً نهائياً. جودة المراجع مرتبطة بوجود نصوص مفهرسة في جدول `legal_articles` وباكتمال OCR للمستندات. يجب مراجعة المواد القانونية وتاريخ نفاذها من مصدرها الرسمي.

## 5) ملاحظات التنبيهات
الإشعارات الموجودة حالياً في التطبيق هي إشعارات داخلية مرتبطة بالجلسات والمهام. التنبيهات المحلية المجدولة حتى عندما يكون التطبيق مغلقاً تحتاج خدمة إشعارات وجدولة على الجهاز، ولا تعتبر هذه النسخة أنها توفرها لمجرد ظهور سجل إشعار داخل التطبيق.
