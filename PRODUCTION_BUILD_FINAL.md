# Production build baseline

This project is pinned to Flutter 3.47.5 stable.

Android toolchain:
- Java 17
- Gradle 8.14
- Android Gradle Plugin 8.11.1
- Kotlin Gradle Plugin 2.2.20
- compileSdk 36
- minSdk 24
- targetSdk 36

The repository uses Kotlin DSL (`build.gradle.kts`), not the old Groovy
`android/build.gradle` file. The root Android compatibility file is therefore
`android/build.gradle.kts`.

Before every clean build:
1. Delete `.dart_tool/` and `build/` if they exist.
2. Run `flutter pub get`.
3. Run `flutter analyze`.
4. Run `flutter test`.
5. Run `flutter build apk --release`.

GitHub Actions performs these checks automatically and uploads:
`build/app/outputs/flutter-apk/app-release.apk`

Do not commit `android/local.properties`, signing keys, or generated plugin
metadata. `.flutter-plugins-dependencies` is regenerated by Flutter.
