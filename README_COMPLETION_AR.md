# منصة الأكرم للمحامين السوريين — نسخة مكتملة وظيفياً

تم استكمال المشروع فوق الملفات الأصلية مع إبقاء نسخة مطابقة من المصادر الأصلية داخل:

`original_source_backup/`

## ما تمت إضافته

- تسجيل حساب محامٍ وتسجيل دخول محلي.
- حفظ بيانات المحامي الأساسية.
- إدارة القضايا:
  - إنشاء قضية.
  - تعديل القضية.
  - حذف القضية.
  - حالة القضية.
  - الموكل والخصم والمحكمة ورقم القضية.
  - ملخص الوقائع وملاحظات المحامي.
- البحث داخل القضايا.
- صفحة تفاصيل القضية.
- ربط المستندات بالقضية.
- تصوير المستندات بالكاميرا.
- اختيار مستند من المعرض.
- قص وتدوير وضبط إطار الصورة.
- حفظ الصورة داخل مساحة التطبيق.
- اسم المستند والوسوم والملاحظات.
- البحث القانوني حسب وصف الوقائع والكلمات المفتاحية.
- اللمحامين السوريينة القانونية الموجودة في المشروع بقيت متاحة.
- الجلسات الموجودة في المشروع بقيت متاحة.
- الموكلون الموجودون في المشروع بقيوا متاحين.
- الإشعارات مع تعليم كمقروء وحذف.
- الملف الشخصي وتسجيل الخروج.
- الصياغة القانونية الأولية لعدة نماذج.
- لوحة رئيسية تعرض إحصائيات القضايا والمستندات والجلسات.
- دعم اتجاه RTL للغة العربية.
- إعدادات Android/iOS اللازمة للكاميرا والصور.

## تشغيل المشروع

من داخل مجلد المشروع:

```bash
flutter pub get
flutter run
```

ولبناء APK:

```bash
flutter build apk --release
```

## ملاحظة مهمة حول الحسابات والبيانات

هذه النسخة تعمل محلياً على الجهاز، ولذلك الحساب والبيانات لا تتزامن بين أجهزة المحامي.

قبل نشر التطبيق تجارياً، المرحلة التالية الموصى بها هي ربط:

- Firebase أو Supabase للمصادقة.
- قاعدة بيانات سحابية للقضايا والموكلين والجلسات.
- تخزين سحابي مشفر للمستندات.
- نسخ احتياطي واستعادة.
- صلاحيات وصول وحماية للملفات.
- تشفير مناسب للبيانات الحساسة.

كما أن البحث القانوني الحالي هو بحث محلي أولي داخل قاعدة مواد، ويجب ربطه لاحقاً بمصدر رسمي محدث للتشريعات السورية، مع حفظ تاريخ الإصدار والتعديلات والاجتهادات.

## تنبيه قانوني

المحتوى القانوني داخل التطبيق لأغراض المساعدة والتنظيم والبحث الأولي، ولا ينبغي اعتباره بديلاً عن مراجعة النص الرسمي النافذ والتعديلات والاجتهادات والاختصاص والمواعيد القانونية.


## ربط Supabase
تم إعداد المشروع باستخدام Project URL وPublishable Key الخاصين بمشروع Supabase الحالي. ملف الإعداد: `lib/core/supabase_config.dart`.
