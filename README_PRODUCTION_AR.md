# منصة الأكرم للمحامين السوريين — نسخة الربط السحابي

هذه النسخة مهيأة لتكون منصة عامة للمحامين السوريين، وليست مرتبطة بمكتب واحد.

## ما تم ربطه
- Supabase Auth للحسابات.
- ملف المحامي من جدول `profiles`.
- القضايا والجلسات والمستندات والإشعارات.
- الموكلون من جدول `clients` بدل البيانات التجريبية.
- المهام من جدول `tasks` مع شاشة إدارة مهام.
- البحث القانوني عبر RPC `search_legal_articles` بدل الفهرس المحلي التجريبي.
- ملفات المستندات في Storage الخاص `legal-documents` مع حذف الملف عند حذف سجل المستند.
- سياسات RLS وعزل بيانات كل محامٍ عن بقية المحامين.

## مهم قبل الإطلاق
1. شغّل migrations بالترتيب:
   - `0001_al_akram_law.sql`
   - `0002_production_hardening.sql`
   - `0003_legal_search_metadata.sql`
2. أدخل النصوص القانونية السورية من مصادر رسمية موثوقة إلى `legal_sources` و`legal_articles` قبل الاعتماد على البحث القانوني.
3. لا تضع `service_role` أو أي Secret key داخل التطبيق.
4. راجع إعدادات Supabase Data API وتأكد من كشف الجداول والدالة المطلوبة للمستخدم `authenticated`.
5. اختبر التسجيل، تسجيل الدخول، RLS، رفع/حذف المستندات، والبحث القانوني على مشروع Supabase الإنتاجي قبل النشر.

## البناء
يمكن تغيير بيانات الاتصال وقت البناء عبر:
`--dart-define=SUPABASE_URL=... --dart-define=SUPABASE_PUBLISHABLE_KEY=...`

المفتاح الموجود داخل التطبيق يجب أن يكون Publishable/Anon فقط؛ الحماية تعتمد على RLS.
